# ADR 003: Typed graph semantics and reviewed promotion

Status: Accepted.

Updated 2026-10-02. Pilot authority clarified; the original typed-graph direction is retained.

**Decision:** Design typed, versioned, regime-scoped economic, thesis, evidence, and outcome relationships now. Store them initially in ordinary tables. Treat rolling correlations as observations, not causal edges. Canonical relationship changes require a named human reviewer during the pilot, with evidence, counter-evidence, rationale, scope/regime, and retained predecessors. Automated outcome-derived proposals and promotion are deferred under ADR 012. Any later designated system-level governance needs separate review; a threshold or model call cannot confer authority.

**Why:** Macro links are conditional and can change by regime. One anomalous reaction must not redefine the knowledge base. A graph database is a storage optimization, not the domain model.

**Rejected:** Flat thesis blobs, automatic edge rewriting from outcomes, static universal correlations, and graph database adoption before measured need.

**Consequence:** Manual knowledge corrections and initial curated relationships need provenance and explicit reviewer authority. A shared model-generated macro context contains disputable hypotheses, not canonical edges. Migration to a graph store remains possible through stable domain contracts. Retrieval of provisional outcome learnings is deferred, rather than an allowed way to bypass review.
