# Recorded research and driver-review proof

Date: 2026-10-15. This proof uses fictional helionite and recorded model adapters through the real session/CSRF API in a disposable PostgreSQL database. It is not market research or evidence of live analytical usefulness.

[Exact retained records](driver-research-trace-2026-10-15.json) | [Reproduction tool](../tools/driver_research_demo.py) | [Generated API schema](driver-research-openapi-2026-10-15.yaml)

## Trace

1. Retain a fictional report about importer replacement costs and select its exact source revision before thesis approval.
2. Compile the exact rough research question using the opted-in profile. The review proposes a possible importer cost/margin mechanism and an indirect equity research candidate. Each has source-claim references and uncertainty; the candidate has basis risks, verification questions and unverified availability. Extracted intent remains distinct.
3. Verify that research alone created zero watches, positions, approvals or notification intents. A separate explicit command approves the exact original text and extracted driver. It does not adopt the proposed driver.
4. Explicitly request a retained-news assessment without an attached trade. Premise support, mechanism challenge and possible thesis progression coexist. Attention is a review recommendation only. Verified price observation is unavailable and entry is not assessed.
5. Assemble a retained daily review including the earlier labelled news analysis, then explicitly request a fresh driver synthesis against that exact review. It has no publication authority.
6. Close database connections, retain a source correction, remove provider credentials and change the configured provider. Read the three saved commands without constructing a provider. Original model documents survive unchanged; current evidence dispositions become stale. Exact approved text, driver and approval remain unchanged.
7. Confirm no watch, paper position, current assessment or notification intent was created. Drop the temporary database without using existing trader records.

## Costs and limits

There is one recorded completion per role: compilation, news and morning synthesis. There are zero real model/network calls and zero real model spend. Model-reported costs remain unknown; fixture catalogue estimates are not charges. Compute and storage costs are unmeasured.

Quotation checks prove retained attribution, not source truth, semantic support or causation. This trace does not prove the importer mechanism or that a useful exposure instrument exists. It shows the required separation and durable records using predetermined outputs.

Source selection remains manual. Automatic contextual investigation, suitable live sources, verified market-price inputs, live immediate driver-change publication and external delivery remain outstanding. A connection restart is not an operating-system crash or an uncertain paid-call test; separate regression tests cover admitted unknown outcomes and runner recovery without automatic resubmission.

## Reproduce

Load the local development database environment, then run:

```sh
MACRO_ENABLE_CONTINUOUS_DESK=1 MACRO_ENABLE_MONITORING_PROOF=1 MACRO_ALLOW_SYNTHETIC_SETUP=1 DJANGO_SETTINGS_MODULE=macro_agent.web.local_settings .venv/bin/python tools/driver_research_demo.py --output .local/new-driver-research-trace.json
```

Choose a new output filename. The tool creates and drops a separate temporary database; it uses recorded provider adapters even if live provider credentials exist in the environment.
