# Daily publication trace, 2026-10-11

The [recorded trace](daily-publication-trace-2026-10-11.json), generated by [the isolated demonstration](../tools/daily_publication_demo.py), proves a deterministic daily digest's publication lifecycle with fictional evidence in a unique temporary PostgreSQL database.

| Step | Result |
| --- | --- |
| Approve exact thesis and attach an incompletely sized paper trade | User authority and missing sizing remain explicit |
| Capture a fictional report and prepare a daily review | Exact evidence, exposure and source versions are retained |
| Publish | Generation 1, exact review, immutable decision and one pending internal intent commit together |
| Recover through fresh database connections | Same saved publication, no rebuilt content or model call |
| Capture a correction | Current pointer clears and pending intent is canceled; original decision remains current in history |
| Retry original command | Original receipt returns with superseded present disposition; no reactivation |
| Prepare and publish a later review | Generation 2 becomes current with a new internal intent |
| Withdraw source permission | Generation 2 loses current authority and its pending intent is canceled |

Real model calls, real feed calls and model spend were all zero. Compute and storage costs were not measured. The temporary database was dropped; no existing trader records were used. The JSON includes exact retained reviews, original inputs, both publication decisions, notification states and audit transitions.

Independent PostgreSQL tests additionally force both correction/publication and permission/publication orders with actual server lock waits. The sequential trace does not substitute for those races, a process-crash test, source entitlement verification or a supervised live week. It contains no fresh model synthesis or verified macro regime and sends no external alert.
