# ADR 019: Bounded question research and qualified driver publication

Status: Internal implementation direction, 2026-10-18, under the user's delegated judgment to develop both functions. This selects neither production sources nor calibrated materiality thresholds or external delivery.

**Research:** Retain an exact user question independently of approval. Run a bounded graph with one planning admission, at most three one-shot GDELT metadata searches and one existing sourced compilation admission. Preserve named questions, counter-evidence sought, selection/exclusion records, exact revisions and unknown costs. Every paid node uses the shared allowance and committed admission before inference. Explicit continuation can advance unadmitted nodes or adopt retained acquisition receipts; uncertain calls are never automatically resent. A private question-backed unapproved draft reuses compilation without asserting belief. Research-only source eligibility and private query ownership remain separate from continuous monitoring.

**Driver publication:** Retained cumulative driver-reviewed analysis enters a separate typed publication contract. Protect source, owner, thesis and brief state, compare exact dependencies and generation, then atomically install current output and internal work. Automatic publication additionally requires a protected current watch/slot lease. Saved decisions remain inert on retry. All governing writers invalidate the complete daily/news dependent union. Generic factual-notice publication cannot operate on these streams.

**Attention:** The explicit `evidence-linked-driver-review-v1` policy admits qualified review for a first or changed typed approved-driver assessment with linked current evidence. It is a conservative operational criterion, not proven market materiality. Advancing an unchanged brief carries unread work with a direct original-request link and complete original dependencies. It does not manufacture another interruption. External delivery, acknowledgement, semantic deduplication and live calibration remain open.

**Why:** This joins the existing auditable components into testable user workflows while keeping rough research separate from monitoring and model output separate from authority. It avoids an open-ended search loop, automatic thesis changes, new framework dependencies and silent paid retries. Bounds and limited source depth remain explicit.

**Evidence and limits:** See [question research](../QUESTION_RESEARCH.md), [driver attention](../DRIVER_ATTENTION.md) and the dated implementation traces. GDELT metadata is an internal experiment; linked articles are not fetched. Recorded responses test mechanics, not research quality, suitable live sources or institutional desk readiness. The paper pilot still requires supervised live evaluation.

**Context amendment, 2026-10-19:** Final research synthesis also consumes a versioned, server-built projection of the immutable plan and every completed discovery outcome. Preserve material/counter-evidence questions, empty results, caps, exclusions and exact revision membership as untrusted workflow data. It cannot supply trader intent or factual quotations, and absence of results cannot establish absence of a driver. Bound the complete packet; preserve legacy packet/prompt hashes when omitted. An independent source-check command makes no paid admission or persistent write. The live transport failure and [replacement review](../../research/research-source-recheck-2026-10-19.md) select no new provider.

**Recovery amendment, 2026-10-20:** The user requested both resumable waiting and explicitly configured source fallback, then authorized continued work. Opted-in `source_recovery` runs permit at most three source-only attempts per named question, twenty-second exchanges, shared minimum spacing, bounded backoff and a thirty-minute source deadline. Preserve original failure/receipt history, successful searches and the exact paid plan. Honor longer server cooldowns; reject duplicate/early admissions and stop before new paid planning when a known provider delay makes source work impossible. Initial-command replay and uncertain paid nodes remain inert. New v3 evidence/v2 question context binds this history; legacy omitted-option requests retain their original identities. See [source recovery](../RESEARCH_SOURCE_RECOVERY.md). These internal bounds are not inferred provider quotas. Alternate-source activation still requires a selected, explicitly configured source contract; none is selected by this amendment. Partial synthesis and automatic source substitution remain unavailable.
